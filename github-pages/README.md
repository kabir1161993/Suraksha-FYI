# Suraksha.fyi — GitHub Pages edition

This is a self-contained GitHub Pages-ready copy of the app. Its original
source folder has not been changed.

## Publish

1. Create a GitHub repository and upload the contents of this folder as that
   repository's root files.
2. In the repository, open **Settings → Pages** and select **GitHub Actions**
   as the source.
3. Push to the `main` branch. The included workflow builds and publishes the
   site automatically.

Routes use `#` (for example `#/map`) so bookmarks and refreshes work on
GitHub Pages without server-side route rewrites.
